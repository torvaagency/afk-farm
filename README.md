# AFK Farming

An idle farming simulator with a focus on long-term progression and a high-fidelity interface.

## Features

- Hardcore progression systems.
- Modern HUD interface.
- Persistent game state.
- Responsive design.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

### Installation

1. Clone the repository.
2. Navigate to the frontend directory: `cd frontend`.
3. Install dependencies: `npm install`.
4. Start the development server: `npm run dev`.
5. Open http://localhost:5173 in your browser.
