# AFK FARM // V1.0

A high-fidelity, "Celestial Magitech" idle farming simulator designed for the modern gamer. Manage your arcane grid, harvest mystical crops, and transmute them into wealth to upgrade your tier.

![AFK Farm HUD](https://via.placeholder.com/1200x600.png?text=AFK+FARM+HUD+PREVIEW)

## 🌌 Features

- **Hardcore Progression**: Exponential leveling curve and long-term crop growth (from seconds to days).
- **Celestial HUD**: High-octane sci-fi interface featuring Orbitron typography, neon-bordered panels, and tactical scanline overlays.
- **Arcane Alchemy**: Discover rare speed elixirs during harvests to boost your grid's chrono-output.
- **Responsive Terminal**: Fully optimized for tactical desktop and mobile management.
- **Persistent State**: Automated local buffer saves your progress across sessions.

## 🛠️ Tech Stack

- **Core**: React 18 + Vite
- **Styling**: Tailwind CSS v4 (Modern HUD Utility classes)
- **Animations**: Framer Motion (Smooth UI transitions & arcane glows)
- **Icons**: React Icons (Game Icons & Font Awesome)
- **State**: Zustand-style persistent hook management

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS)
- npm or pnpm

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/wraith22444/afk-farming.git
   cd afk-farming
   ```

2. **Install dependencies**:
   ```bash
   cd frontend
   npm install
   ```

3. **Ignite the Core**:
   ```bash
   npm run dev
   ```

4. **Access the Interface**:
   Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📜 System Commands

- **PURCHASE**: Acquire seeds from the bazaar.
- **SELECT**: Imbue your grid with the chosen essence.
- **HARVEST**: Extract yields and experience.
- **TRANSMUTE**: Convert crops into monetary currency.
- **WIPE_MEMORY**: Perform a complete system reset (Danger).
